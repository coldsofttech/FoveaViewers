# Support

- **Using a viewer:** start with the README of the package you installed, for example `packages/fovea-markdown/README.md`.
- **Questions and ideas:** open an issue and choose the feature request form, or ask in [GitHub Discussions](../../discussions) if it is enabled.
- **Bugs:** open an issue with the bug report form. Name the package and its version, and attach a small sample file if you can.
- **Security problems:** see [SECURITY.md](SECURITY.md).
