Fovea Viewers sample page

A web page to try the HTML viewer on.

Styles and layout

This page has its own stylesheet, a gradient header and cards. By default only the styles in this file apply, as nothing is loaded from the web. A table:

Option Default Turned on
Pictures, styles, fonts Only what is in the file Loaded from the web
Links Do nothing Open in the viewer or a new window
Scripts Never run Run, in a frame of their own
