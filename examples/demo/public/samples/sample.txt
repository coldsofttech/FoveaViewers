FOVEA VIEWERS - SAMPLE TEXT FILE
================================

This is a plain text file for trying the text viewer. Each line gets a number
in the margin, and only the lines in view are drawn, so even a very large
file opens at once.

1. Things to try
----------------

  * Scroll up and down, or click the viewer and use Page Up, Page Down,
    Home and End.
  * Switch between the light and dark themes.
  * Scroll sideways along the long line further down.
  * Select some text and copy it. The line numbers are not copied.

2. Tabs and spacing are kept as they are
-----------------------------------------

Name		Role		City
Ada		Engineer	London
Grace		Admiral		New York
Linus		Maintainer	Portland

    Four spaces of indentation stay four spaces.
        Eight stay eight.
